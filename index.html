🔗 Integração GitHub

Os dados são armazenados em um arquivo JSON no seu repositório GitHub. Configure abaixo o repositório e token de acesso.

O token fica salvo localmente neste browser. Permissões necessárias: repo (read/write contents).
💾 Backup dos dados

Baixe uma cópia de segurança de todos os dados (vendas, produtos, comodato, mapa de custos, custo fixo) como um arquivo. Guarde numa pasta sua ou no drive da empresa. Recomendado: uma vez por mês, ou após mudanças grandes.

Restaurar de um backup: selecione um arquivo de backup baixado anteriormente. Atenção: isso substitui todos os dados atuais.
